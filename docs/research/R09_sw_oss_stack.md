Notes for F1:
- GarmentCode is the only option that is (a) programmatic, (b) MIT, (c) already produces a stitch-aware flat pattern representation suitable for M02 and the assembly compiler M06. Its risks are single-maintainer status and no release since April 2025; mitigate by vendoring a pinned fork.
- CLO and Browzwear APIs are plugin SDKs that run inside their desktop apps; they cannot be used as headless services in M03.
